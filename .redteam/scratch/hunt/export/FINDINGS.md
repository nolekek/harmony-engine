## Раздел «НЕ подтвердилось» (Ложные гипотезы и корректные места)

1. **Валидность структуры MusicXML для всех стандартных метров (4/4, 3/4, 2/4, 6/8, 3/8)**:
   - *Гипотеза*: сложный метр 6/8 или 3/8 вызовет переполнение такта, расхождение divisions или падение `xml.etree.ElementTree`.
   - *Факт*: **НЕ подтвердилось**. Во всех проверенных размерах (4/4, 3/4, 2/4, 6/8, 3/8) сумма длительностей строго равна `beats * divisions * 4 / beat_type` (в 4/4 = 16, 3/4 = 12, 2/4 = 8, 6/8 = 12, 3/8 = 6 при divisions=4). Автодополнение паузами (`STANDARD_REST_DURS`) корректно закрывает остаток такта.
2. **Переполнение тегов `<backup>`**:
   - *Гипотеза*: тег `<backup>` отматывает больше длительности такта при многоголосии SATB.
   - *Факт*: **НЕ подтвердилось**. Значение `<duration>` внутри `<backup>` строго равно `m_total_divisions` текущего такта (16, 12, 8, 6), откат происходит ровно на границу такта.
3. **Разрезание нот через тактовую черту (Barlines & Ties)**:
   - *Гипотеза*: ноты длиннее остатка такта не лигуются или теряют теги `<tie>` / `<tied>`.
   - *Факт*: **НЕ подтвердилось**. Слайсы корректно делятся на части, первая получает `<tie type="start">`, промежуточные — `type="stop"` и `type="start"`, финальная — `type="stop"`.
4. **Тональные знаки и энгармонизм (Fifths & Alter)**:
   - *Гипотеза*: в тональностях с бемолями генерируются диезы или путаются ступени/alter.
   - *Факт*: **НЕ подтвердилось**. Проверены все 24 канонические тональности от -6 до +7 квинт: при `fifths < 0` выбирается `FLAT_SPELLING` (alter = -1), при `fifths > 0` — `SHARP_SPELLING` (alter = 1).
5. **Спецификация MIDI Type 1**:
   - *Гипотеза*: каналы смешаны, Program Change не 52, Note-Off не сходятся с Note-On, темп искажает тики.
   - *Факт*: **НЕ подтвердилось**. Генерируется валидный MIDI Type 1 с 4 треками (Soprano, Alto, Tenor, Bass), каналы 0..3, Program Change 52 (Choir Aahs), количество Note-On строго равно Note-Off, расчет тиков через `ticks_per_beat = 480` корректен.
6. **Ошибки сборки фронтенда (`npm run build`)**:
   - *Гипотеза*: TypeScript или Vite упадут с ошибками компиляции.
   - *Факт*: **НЕ подтвердилось**. `npm run build` успешно собирает продакшн-бандл за ~780 мс без ошибок компиляции TypeScript.
