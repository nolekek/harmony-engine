## 2. Раздел «НЕ подтвердилось» (Опровергнутые гипотезы и защищённые механизмы)

1. **Path Traversal в `/api/import-file` (через имя файла): НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Передача параметров вида `../../../../etc/passwd` или `..\\..\\win.ini` позволяет прочитать или перезаписать файлы на диске.
   - *Фактическое поведение:* Функция `api_import_file` (`backend/api.py:273-343`) производит парсинг исключительно в оперативной памяти из полученного буфера байт/base64 (`ET.fromstring`). Значение `filename` нигде не передаётся в функции файловой системы (`open`, `Path`, `os.remove`). Эскалация на файловую систему невозможна.

2. **DoS / Зависание сервиса на 128 нотах: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Длинная мелодия (граничное значение 128 нот) вызовет комбинаторный взрыв в Viterbi / грамматике и положит сервис по таймауту.
   - *Фактическое поведение:* Запрос со 128 нотами выполнился за **1194.99 мс** (серверное время) / **1521.48 мс** (полный HTTP roundtrip). Алгоритм Витерби работает со сложностью $O(N \cdot K^2)$ и масштабируется строго линейно по длине мелодии. Сервер сразу после этого отдаёт `200 OK` на `/api/health`. Попытка передать 129 нот корректно отсекается валидатором Pydantic (`422 Unprocessable Entity`).

3. **Утечка стектрейсов (Stack Trace Leakage) в ответах 500: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* При возникновении исключений бэкенд выплёвывает внутренний Python-стектрейс наружу клиенту.
   - *Фактическое поведение:* Глобальный обработчик `unhandled_exception_handler` (`backend/main.py:47-73`) перехватывает все исключения, генерирует уникальный `error_id`, пишет полный трейс в закрытый логгер сервера и отдаёт наружу стерильный JSON: `{"detail": "Internal Server Error", "error_id": "..."}`.

4. **Выставление оценки «5 (Отлично)» на кривых решениях в `/api/grade`: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Студент может подсунуть некорректное голосоведение (унисоны, отсутствие обязательной терции, параллельные квинты/октавы, перекрещивание голосов) и получить зачёт.
   - *Фактическое поведение:* Консерваторский инспектор `grade_satb_solution` (`backend/grader.py`) жёстко детектирует нарушения:
     - Унисон соседних голосов: `VOICE_UNISON`, оценка **«2 (Не зачтено / Полный разнос)»**.
     - Отсутствие терцового тона: `CHORD_THIRD_MISSING`, оценка **«2 (Не зачтено / Полный разнос)»**.
     - Параллельные квинты: `PARALLEL_FIFTHS`, оценка **«2 (Не зачтено / Полный разнос)»**.
     - Сопрано ниже альта: `VOICE_CROSSING` (8 жестких нарушений), оценка **«2 (Не зачтено / Полный разнос)»**.

5. **Обход CORS с произвольных доменов (`Origin: http://evil.com`): НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* CORS сконфигурирован с `allow_origins=["*"]` или доверяет чужим Origin.
   - *Фактическое поведение:* `CORSMiddleware` (`backend/main.py:76-87`) содержит строгий белый список (`127.0.0.1:8000`, `localhost:8000`, `127.0.0.1:5173`, `localhost:5173`). Запросы с `Origin: http://evil.com` получают `400` на preflight OPTIONS и не получают заголовок `Access-Control-Allow-Origin` на POST.

6. **Потоконебезопасность / Состояние гонки (Race Condition) при параллельных запросах: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Синглтон `HarmonizationService` разделяет мутабельное состояние между запросами.
   - *Фактическое поведение:* Два параллельных асинхронных запроса на гармонизацию разных мелодий в разных тональностях завершились за 812.9 мс параллельно, вернув независимые математически корректные результаты без порчи данных.

7. **Недетерминизм гармонизации: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Повторные вызовы `/api/harmonize` на одной и той же мелодии возвращают разный порядок кандидатов или рандомные планы.
   - *Фактическое поведение:* 100% повторяемость побайтово (`is_deterministic = True`).

8. **Возврат HTML 404 на неизвестные маршруты API: НЕ ПОДТВЕРДИЛОСЬ.**
   - *Гипотеза:* Несуществующий эндпоинт `/api/unknown` перехватывается SPA-роутером и возвращает HTML страницы.
   - *Фактическое поведение:* Fallback-обработчик (`backend/main.py:99-101`) гарантирует структурированный ответ `{"detail": "Not Found"}` со статусом 404 и `Content-Type: application/json`.
