# 🎼 Brigade Classical 4-Part Harmony Engine (Бригадный учебник)

Высокоточный, алгоритмически строгий нейро-символический движок классической четырехголосной гармонизации (SATB) по правилам канонического учебника гармонии (И. Дубовский, С. Евсеев, И. Способин, В. Соколов).

Написан с нуля на чистом стандартном Python 3.14+ без внешних C-зависимостей.

---

## 🏛️ Архитектура

В отличие от наивных бэктрекинг-солверов или вероятностных нейросетей (выдающих параллельные квинты, перекрещивания и функциональный бред вроде $D \to S$), движок реализует иерархическую модель:

```
                  [Входная мелодия / Soprano]
                              │
                              ▼
        ┌───────────────────────────────────────────┐
        │       Macro Syntax Engine (CFG)           │  <-- Грамматика функций и кадансов
        └─────────────────────┬─────────────────────┘
                              │ Допустимые планы (T, S, D, K64...)
                              ▼
        ┌───────────────────────────────────────────┐
        │       State Lattice & Rule Pruning        │  <-- Генерация срезов SATB
        └─────────────────────┬─────────────────────┘
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
   ┌───────────────────────┐   ┌───────────────────────────┐
   │ Hard Gates (0 косяков)│   │ Soft Cost / Style Priors  │  <-- Сюда подключается
   │ - Параллельные 5 и 8  │   │ - Плавность голосоведения │      легковесная нейронка
   │ - Скрытые 5 и 8       │   │ - Тесситурный комфорт     │
   │ - Удвоения и септимы  │   │ - Композиторский стиль    │
   └───────────┬───────────┘   └─────────────┬─────────────┘
               │                             │
               └──────────────┬──────────────┘

        │          Viterbi DP Optimizer             │  <-- O(N * K^2) глобальный оптимум
        └─────────────────────┬─────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────────┐
        │        Multi-Format Score Exporters       │  <-- MusicXML, MIDI, ASCII
        └───────────────────────────────────────────┘
```

## 🚀 Быстрый старт

### 1. Запуск через консольный CLI

Гармонизация мелодии одной командой:
```bash
python -m src.harmony.cli --melody "64,65,67,62,60" --tonic C --mode Major --musicxml output/result.musicxml --midi output/result.mid
```

Параметры:
- `--melody`: Номера высот в стандарте MIDI через запятую (например, `64,65,67,62,60` для `E4, F4, G4, D4, C4`).
- `--tonic`: Тоника (`C`, `G`, `F#`, `Bb`, `A`...).
- `--mode`: Лад (`Major` или `Minor`).
- `--musicxml`: Путь для сохранения партитуры MusicXML (открывается в MuseScore, Sibelius, Finale).
- `--midi`: Путь для сохранения полифонического аудиофайла MIDI Format 0.

---

### 2. Использование через Python API

```python
from src.harmony.pipeline import Harmonizer
from src.harmony.core.types import Key

harmonizer = Harmonizer()
key = Key("C", "Major")

# Мелодия с разметкой метрических долей
melody = [
    {"pitch": 64, "is_downbeat": True},
    {"pitch": 65, "is_downbeat": False},
    {"pitch": 67, "is_downbeat": True},
    {"pitch": 62, "is_downbeat": False},
    {"pitch": 60, "is_downbeat": True},
]

result = harmonizer.harmonize(melody=melody, key=key)

if result.is_success:
    solution = result.best_solution
    print(solution.ascii_score)
    solution.save_musicxml("output/solution.musicxml", title="Гармонизация в До-мажоре")
    solution.save_midi("output/solution.mid")
```

## 📋 Реализованные правила Бригадника

Все правила формализованы в машиночитаемом каталоге [`docs/brigade_rules.json`](docs/brigade_rules.json) и спецификации [`docs/BRIGADE_RULES.md`](docs/BRIGADE_RULES.md):

| Категория | Правило | Статус |
|-----------|---------|--------|
| **Диапазоны** | S (C4-A5), A (G3-D5), T (C3-G4), B (E2-C4) | Hard Gate |
| **Расположение** | Тесное ($\le 4^{ta}$), широкое ($5^{ta}-8^{va}$), смешанное | Hard Gate / Penalty |
| **Интервалы голосов** | Расстояние между S-A и A-T не более октавы | Hard Gate |
| **Перекрещивание** | Перекрещивание и переплывание голосов запрещены | Hard Gate |
| **Параллелизмы** | Параллельные и противоположные квинты и октавы | Hard Gate |
| **Скрытые 5 и 8** | Прямое движение крайних голосов к совершенному консонансу | Hard Gate |
| **Мелодика** | Запрещены ходы на увеличенные интервалы и септимы | Hard Gate |
| **Удвоения** | В трезвучиях удваивается прима; в $K^6_4$ строго бас (квинта) | Hard Gate |
| **Прерванный оборот** | В $VI$ ступени после $D$ строго удваивается терция | Hard Gate |
| **Разрешения** | Септима разрешается на ступень вниз; $D^4_3 \to T_6$ | Hard Gate |
| **Синтаксис** | Недопустимость регрессии $D \to S$; $K^6_4$ только на сильной доле | Hard Gate |

## 🧠 Интеграция с легковесной нейросетью (Neuro-Symbolic)

Движок разработан как фундамент для гибридного искусственного интеллекта:
1. **Синтез данных:** `Harmonizer` генерирует 50 000+ валидных гармонизаций для обучения с нулевым процентом ошибок.
2. **Нейронный оценщик стиля:** Легковесная Bi-GRU модель выдаёт логиты предпочтений голосоведения, которые подаются в `RuleEngine.compute_soft_cost()`.
3. **Безупречный результат:** Алгоритм Витерби оптимизирует итоговую партитуру, гарантируя математическую чистоту академического стиля без единого нарушения правил.
